# Pi Web UI 设计规范

版本：v0.1
日期：2026-11-24
依据：[PRD.md](PRD.md) v0.2（中文为主、Preact+Vite、亮色基准）

## 1. 设计基调

- **风格**：现代对话产品（类 Claude.ai），柔和圆角、留白充足、阴影极轻。
- **主色**：黑白灰单色系。交互强调色即"黑"本身（黑底白字按钮、黑色描边）；不引入品牌彩色。
- **功能性颜色只用于语义**：diff 增删、错误、成功、运行中 spinner，其余一律灰阶。
- **布局**：文档流式——消息按角色全宽排列，角色用名字与小头像点区分，不用左右气泡。
- **字体**：正文 Sans（系统无衬线栈），代码/终端输出/diff/路径/JSON 用等宽双轨。
- **密度**：宽松阅读型。行高 1.7，消息间距大，一屏少而精。
- **主题**：本规范定义亮色基准 token；暗色在 M4 由同一套 token 派生（见第 7 节）。

## 2. 颜色 token（亮色基准）

CSS 变量定义在 `:root`，命名 `--c-*`。黑白系只有灰阶 + 4 个功能色。

### 2.1 灰阶

| token | 值 | 用途 |
|---|---|---|
| `--c-bg` | `#ffffff` | 页面背景 |
| `--c-bg-subtle` | `#f7f7f5` | 次级背景：用户消息底、侧栏、卡片 hover |
| `--c-bg-inset` | `#efefec` | 代码块、bash 输出、输入框内嵌区背景 |
| `--c-fg` | `#1a1a19` | 主文字 |
| `--c-fg-secondary` | `#6b6b68` | 次级文字：时间戳、角色名辅助、占位符 |
| `--c-fg-tertiary` | `#a3a3a0` | 弱文字：禁用、极弱提示 |
| `--c-border` | `#e3e3e0` | 常规边框、卡片描边 |
| `--c-border-strong` | `#1a1a19` | 强调边框：输入框聚焦、选中态（黑） |
| `--c-inverse-bg` | `#1a1a19` | 主按钮底、选中项底 |
| `--c-inverse-fg` | `#ffffff` | 主按钮文字 |

### 2.2 功能色（唯一允许的彩色）

| token | 值 | 用途 |
|---|---|---|
| `--c-error` | `#c9412e` | 工具出错、连接断开、中止失败 |
| `--c-success` | `#3d7a3d` | diff 新增行文字、成功提示 |
| `--c-warning` | `#b37d1e` | 队列中、重试中、协议不匹配警告 |
| `--c-running` | `#1a1a19` | 运行中 spinner/呼吸点（黑色，同主色） |

diff 底色用同色 12% 透明度（`--c-success` / `--c-error` over `--c-bg-inset`）。

### 2.3 使用规则

- 界面中除上表 4 个功能色外不出现任何彩色。Markdown 链接用主文字色 + 下划线，不用蓝。
- 选中/激活态一律"黑描边或黑底"，不用彩色高亮。
- 错误提示 = `--c-error` 文字或左侧 2px 色条，不整块刷红。

## 3. 字体

| 用途 | token | 栈 |
|---|---|---|
| 正文 | `--font-sans` | `-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif` |
| 代码 | `--font-mono` | `"JetBrains Mono", "Cascadia Code", Consolas, "SFMono-Regular", monospace` |

- 正文字号 `15px`，行高 `1.7`；消息流正文最大宽度 `720px` 居中。
- 代码字号 `13px`，行高 `1.55`；代码块内不换行，横向滚动。
- 字号阶梯：`12 / 13 / 15 / 17 / 20`。17 用于卡片标题，20 用于会话名等页面级标题；其余场景只用 15/13/12。
- 中英文混排不加空格处理（交给浏览器），等宽内容里的中文按字符宽度自然排列。

## 4. 页面结构

```
+------------------------------------------------------+
| 顶栏 56px: 会话名 | 状态点 | 模型/推理档 | 设置图标   |
+------------------------------------------------------+
|                                                      |
|           消息流 (max-width 860px 居中)               |
|           - 角色: 用户 / assistant / 工具卡片          |
|                                                      |
|           [滚动跟随, 底部悬浮"回到底部"]               |
|                                                      |
+------------------------------------------------------+
|        悬浮输入框 (max-width 860px 居中, 底部 24px)    |
+------------------------------------------------------+
```

- **顶栏**：高 56px，白底 + 底部 1px `--c-border`。左侧会话名（20px 可截断），右侧依次：运行状态点、当前模型名（13px）、推理档、设置。M1 不做左栏会话列表（PRD 已定）。
- **消息流**：可滚动主区域，内容列 `max-width: 860px` 居中；正文块（assistant 文本、用户消息）再收窄到 `720px`。
- **抽屉**（M2/M3）：设置、Bash 面板、会话树从右侧滑出，宽 `400px`，白底 + 左侧 1px 边框 + 轻阴影。
- **全屏视图**：Git 是覆盖整页的独立视图（F-29），不占抽屉位，视觉规则见 §6。
- **输入框**：悬浮居中卡片，圆角 `16px`，白底，1px `--c-border`，聚焦时 `--c-border-strong` + 极轻投影（`0 2px 12px rgba(0,0,0,.08)`）。内部：多行 textarea 自增高（min 1 行，max 8 行），底部工具行——左：附件按钮、队列指示；右：发送（黑底白字胶囊按钮）/运行中变"停止"（描边按钮）。

## 5. 消息流组件

### 5.1 通用

- 消息间距 `24px`；同一 assistant 回复内段落间距 `12px`。
- 角色标识：用户消息为 `--c-bg-subtle` 底 + 圆角 `12px` 的整块（右侧无头像）；assistant 消息无底色，顶部一行 `13px` 角色行（圆点 6px 黑色 + "pi" + 时间戳 `--c-fg-secondary`）。
- 悬浮消息出现操作按钮（复制、重试 M3），仅 hover 显示。

### 5.2 Markdown 渲染（F-10）

- 标题、列表、引用、表格按 Markdown 标准样式，颜色全部走灰阶 token。
- 行内代码：`--c-bg-inset` 底 + `--font-mono` 13px。
- 代码块：`--c-bg-inset` 底、圆角 `8px`、右上角复制按钮（hover 显示）、hljs 亮色主题且仅取灰阶+功能色子集（自定义 hljs 主题，禁用其彩色配色）。

### 5.3 Thinking 折叠块（F-11）

- 默认折叠：一行 `13px`，前缀"已思考"+ 时长，颜色 `--c-fg-secondary`，左侧 2px `--c-border` 竖条。
- 展开：内容 13px `--c-fg-secondary`，同竖条缩进。

### 5.4 工具卡片（F-12/13/14）

统一容器形态：独立卡片。

```
+------------------------------------------------+
| ⚙ bash   ~/pi/packages   12.3s        [状态]   |   ← 头行 13px
+------------------------------------------------+
| 卡片体（按工具类型渲染）                          |
+------------------------------------------------+
```

- 卡片：白底、1px `--c-border`、圆角 `10px`，与消息流同宽（不收窄到 720px）。
- 头行：工具名（等宽 13px）+ 关键参数摘要（路径/命令首段，截断）+ 耗时 + 状态。
- 状态样式：进行中 = 头行右侧 spinner；成功 = 无标记；出错 = 头行文字与左边条 `--c-error`。
- **bash**：卡片体为等宽终端区（`--c-bg-inset` 底、黑字），`partialResult` 到达即追加，自动滚底；上限保留最近 500 行，更早折叠为"…展开早期输出"。
- **edit/write**：diff 视图，增行绿底/删行红底（功能色 12%），行号 12px `--c-fg-tertiary`，等宽 13px。
- **read/grep/glob 等只读工具**：头行 + 单行结果摘要，默认折叠卡片体，点击展开完整输出（等宽）。
- 卡片可整体折叠：折叠后只留头行。

### 5.5 运行与队列指示（F-04/05/16）

- 运行中：顶栏状态点呼吸（黑色），最后一条 assistant 消息底部行内 spinner + "运行中…"；发送按钮变"停止"。
- 队列：输入框上方出现胶囊条 `--c-bg-subtle` 底："排队中 2 条 · 插话 1 条"，点击展开列表，可单条移除（`clear_queue`）。
- disposition 反馈（F-08）：发送瞬间在输入框上方显示一次性轻提示 toast（12px，2s 消失）："已开始运行 / 已加入队列 / 已交给扩展处理"。

### 5.6 Token 与费用（F-17）

- 每条 assistant 消息角色行右侧灰字：`↑1.2k ↓3.4k · $0.0123`，12px `--c-fg-tertiary`，hover 显示明细（缓存 tokens）。
- 会话累计放顶栏设置弹层或右抽屉（M3 `get_session_stats`）。

## 6. Git 视图（F-29）

覆盖整页的独立视图（`position: fixed; inset: 0`，层级高于所有抽屉），Esc 退出。三栏：改动、历史、diff。

```
+---------------+--------------+-------------------------+
| 顶栏 44px --c-bg-subtle: Git | 分支 pill | 获取 拉取 推送 刷新 关闭 |
+---------------+--------------+-------------------------+
| 改动栏 340px   | 历史栏 280px  | diff 面板                |
| 提交框         | 提交列表      | 文件 / 提交头 34px        |
| 分组 + 文件行   | sha + 标题    | 工具条 26px               |
|               |              | 行列表（18px 行高）        |
+---------------+--------------+-------------------------+
```

- **分栏**：改动栏与历史栏同为 `--c-bg-subtle`，宽度固定 340px / 280px 不可拖动；diff 面板 `--c-bg` 占满剩余。三栏只靠底色与 1px `--c-border` 分隔，不叠阴影。两栏各自滚动，都不带标题行。
- **密度**：文件行与分组头 22px；历史行两行（sha 10px + 标题 12px），作者与时间放 `title`；diff 行 18px、12.5px 等宽。
- **按钮**：只有一种形态——无边框文字按钮，`--c-fg-secondary`，悬停出 `--c-bg-inset` 底色并转 `--c-fg`；危险操作悬停转 `--c-error`；不使用填充按钮。
- **选中态**：左侧 2px `--c-fg` 竖条 + `color-mix(fg 8%)` 底色，文件行与历史行一致。
- **diff 行底色**：新增 12% `--c-success`、删除 12% `--c-error` 混入背景；行号栏与标记栏取同一个 `--row-bg` 上色并 `position: sticky` 固定在左侧，横向滚动时不透出背后文字。
- **网络操作**：顶栏「获取」（`fetch --prune`）、「拉取」（`pull --ff-only`）、「推送」（贴 `gv-primary`，带 `↑n` 计数）。前两者需要当前分支有上游：没有上游或处于游离 HEAD 时按钮置灰，`title` 直接给出要执行的命令；拉取仅在 `behind > 0`、推送仅在 `ahead > 0` 时可点。推送先确认，拉取不确认（非快进时 git 自己拒绝）。三者共用 120 秒网络超时，并设置 `GIT_TERMINAL_PROMPT=0`，缺凭据时立刻报错而不是挂住。
- **AI 生成**：提交框顶部一行右对齐的「AI 生成」文字按钮（无改动或生成中置灰，生成中显示「生成中…」）；点击后用 `pi --mode text` 一次性生成提交说明替换输入框内容，已有文字先确认覆盖，失败只进顶部提示条。
- **行内操作**始终可见但压成 `--c-fg-tertiary`，悬停该行升到 `--c-fg-secondary`，不做隐藏式 hover 菜单。
- **危险操作**（丢弃、删除、reset 等）走居中弹窗确认：`--c-bg` + 1px `--c-border` + `--shadow-md`。

## 7. 输入与交互细节

- **发送**：Enter 发送，Shift+Enter 换行；输入中 textarea 自增高。
- **图片附件**（F-15）：附件按钮 + 粘贴；缩略图 64px 高、圆角 8px、右上角 x 移除，显示在 textarea 上方一排。
- **中止**：运行中"停止"按钮描边样式；点击后立即变灰并显示"正在停止…"，`agent_settled(aborted=true)` 后恢复。
- **toast**：右下角，白底 1px 边框圆角 8px，12px 文字，2.5s 自动消失，错误 toast 用 `--c-error` 左边条、不自动消失。
- **空状态**：无消息时消息流中央显示会话名 + 一行引导"输入内容开始对话"，灰色。

## 8. 暗色派生规则（M4 预留）

所有颜色必须通过 token 引用，禁止硬编码。暗色实现 = 仅替换 token 值：

| 亮色 | 暗色 |
|---|---|
| `--c-bg #ffffff` | `#1c1c1a` |
| `--c-bg-subtle #f7f7f5` | `#262624` |
| `--c-bg-inset #efefec` | `#2e2e2b` |
| `--c-fg #1a1a19` | `#e8e8e5` |
| `--c-fg-secondary` | `#9a9a96` |
| `--c-border #e3e3e0` | `#3a3a37` |
| 功能色提亮一档（`--c-error #e06a56` 等） | 同左 |

阴影在暗色下加重、边框对比减弱，其余组件结构不变。

## 9. 验收清单

- [ ] 界面中不出现任何彩色（除 4 个功能色与 diff）
- [ ] 所有颜色引用 token，无硬编码
- [ ] 正文/代码字体双轨正确，代码块等宽不换行
- [ ] 消息流 860px / 正文 720px 双列宽正确
- [ ] 工具卡片三态（进行中/成功/出错）样式齐备
- [ ] 输入框悬浮居中、聚焦描边变黑、运行中按钮切换
